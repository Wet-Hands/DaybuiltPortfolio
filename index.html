📄 About
WritePath is a minimalist blogging and writing tool built for people who want to focus on words, not configuration. It supports Markdown natively, renders a live preview as you type, and lets you export finished pieces as PDF, clean HTML, or plain text.

Themes can be swapped in one click — no CSS knowledge needed. Everything is stored locally; no account required to get started.
